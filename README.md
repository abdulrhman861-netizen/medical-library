# مكتبة كلية الطب الرقمية

نظام ويب عربي لإدارة طلبات الطباعة والملفات والصور والحسابات اليومية لمكتبة كلية الطب.

## النطاق المعتمد

- بوابة الطالب لرفع الصور وملفات PDF وتحديد متطلبات الطباعة ومتابعة حالة الطلب فقط.
- بوابة الموظف لاستلام الملفات، تحديث حالة الطلب، وإضافة المبيعات والمصروفات اليومية.
- لوحة المدير لإدارة الموظفين وكلمات مرورهم، ومراجعة التفاصيل المالية وإصدار التقارير.
- تخطيط صور يوزع صور عدة أشخاص على صفحة واحدة، مع عدد نسخ مستقل لكل صورة؛ الإعداد المبدئي 3×3.
- رفع الملفات من الهاتف، ومشاركة الملفات من Telegram أو WhatsApp حيث يدعمها الهاتف والمتصفح.
- الطباعة عبر طابعات Wi‑Fi بعد تهيئتها على حاسبة المكتبة أو موبايلات الموظفين.

## البدء

راجع [دليل الإعداد والتشغيل](docs/SETUP_AR.md) لتجهيز Node.js وقاعدة PostgreSQL وتخزين الملفات الخاص. متطلبات المشروع ومهامه موثقة في [خطة المشروع](docs/PROJECT_PLAN_AR.md).

## الحالة الحالية

الموجود في المستودع نموذج أولي للواجهة والخادم. لم تُجهز قاعدة البيانات أو مساحة التخزين أو الاستضافة بعد، ولم تُجرّب الطباعة على أجهزة المكتبة. أكمل الإعداد والتحقق قبل استخدام بيانات طلاب حقيقية.

## الأمان

- لا ترفع ملفات الطلاب أو كلمات المرور أو مفاتيح الخدمات أو ملفات .env إلى GitHub.
- أبقِ تخزين الملفات خاصًا، ولا تعرض ملفات الطلب للطالب بعد الإرسال.
- بيانات مكتبة الطب مستقلة عن قاعدة ومشروع مكتبة الهندسة الرقمية.
