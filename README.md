# مكتبة كلية الطب الرقمية

نظام ويب عربي لإدارة طلبات الطباعة والملفات والصور والحسابات اليومية لمكتبة كلية الطب.

## النطاق المعتمد
- بوابة الطالب لرفع الصور وملفات PDF وتحديد متطلبات الطباعة ومتابعة حالة الطلب فقط.
- بوابة الموظف لاستلام الملفات، تحديث حالة الطلب، وإضافة المبيعات والمصروفات اليومية.
- لوحة المدير لإدارة الموظفين وكلمات مرورهم، ومراجعة التفاصيل المالية وإصدار التقارير.
- محرر صور يوزع صور عدة أشخاص على صفحة واحدة، مع عدد نسخ مستقل لكل صورة؛ الإعداد الابتدائي 3×3.
- استقبال الملفات من الهاتف، بما فيها المشاركة من تطبيقات المراسلة حيث يدعمها الجهاز والمتصفح.
- الطباعة عبر الطابعات المتاحة على شبكة Wi‑Fi من حاسبة المكتبة أو الموبايل بعد تهيئة الطابعة على الجهاز.

## الحالة
المستودع مستقل. التطبيق يحتاج إعداد قاعدة بيانات وتخزين ملفات خاصين قبل التشغيل متعدد الأجهزة.

## الأمان
- لا ترفع ملفات الطلاب أو كلمات المرور أو مفاتيح الخدمات أو ملفات .env إلى GitHub.
- تحفظ الملفات في تخزين خاص ولا تعرض للطالب بعد إرسال الطلب.
- تبقى بيانات مكتبة الطب منفصلة عن قاعدة ومشروع مكتبة الهندسة.
