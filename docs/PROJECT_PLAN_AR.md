# خطة مشروع مكتبة الطب

آخر تحديث: 2026-10-26

مشروع مستقل عن مكتبة الهندسة الرقمية في مستودع `medical-library`. الكود الأساسي جاهز للنشر الأولي؛ لا توجد حتى الآن قاعدة بيانات أو مساحة ملفات أو خدمة Render فعلية مرتبطة بالمشروع الطبي.

## المتطلبات والقرارات

| المجال | القرار |
|---|---|
| الطالب | رفع الصور والمستمسكات وملفات PDF، تحديد عدد النسخ، ومشاهدة حالة الطلب فقط برمز متابعة خاص |
| إدخال الملفات | اختيار الملفات أو سحبها من الجهاز؛ مشاركة الملفات إلى تطبيق Android المثبت من Telegram وWhatsApp |
| الموظف | استلام الملفات وتنزيلها، تحديث حالات الطلبات، إضافة المبيعات والمصروفات اليومية |
| المدير | إدارة حسابات الموظفين وكلمات مرورهم، مشاهدة التفاصيل المالية، وتصدير تقارير CSV اليومية |
| الصور | صور عدة أشخاص في الطلب الواحد مع عدد نسخ مستقل لكل صورة؛ توزيع حتى 9 صور في الصفحة ثم تكملة أوراق أخرى |
| الورق | A4 وA5 و10×15 سم، مع قياس مخصص وهوامش قابلة للتعديل؛ يلزم تأكيد القياس الفعلي ميدانيًا |
| الطابعات | الطابعة 01 — Epson AM-C400 Series؛ 02 — iR-ADV 8585/8595؛ 03 — KONICA MINOLTA C554SeriesPCL؛ 04 — Canon الأبيض؛ 05 — Canon رصاصي |
| الطباعة | من نافذة الطباعة في Windows أو الهاتف بعد تعريف الطابعة على الجهاز؛ لا يوجد إرسال مباشر إلى طابعة المكتبة من خادم الويب |
| الاستضافة | Render كما في مكتبة الهندسة؛ خدمة المشروع الطبي وقاعدة Supabase الطبية لا تزالان بحاجة إلى الإنشاء والربط |
| الملازم | مرحلة لاحقة: إضافة الأقسام والكليات والمراحل والملازم |
| الهوية | شعار الكلية سيضاف بعد استلامه |
| الخصوصية | المستودعان يبقيان عامّين أثناء التطوير، ويعاد ضبطهما إلى خاصّين بعد اكتمال النشر والتجهيز حسب طلب المستخدم |

## الطابعات الظاهرة في Windows

**التسميات المقترحة للطابعات الفعلية:**

1. `01 - Epson AM-C400 Series` (تظهر رسالة خطأ تعريف).
2. `02 - iR-ADV 8585/8595`.
3. `03 - KONICA MINOLTA C554SeriesPCL` (يظهر تنبيه انخفاض الحبر).
4. `04 - Canon الأبيض`.
5. `05 - Canon رصاصي`.

تطبيق التسميات يتم على حاسبة المكتبة نفسها. يجب مطابقة أسماء Windows في نافذة الطباعة؛ إعادة التسمية الفعلية، تعريف Epson، ومعالجة تنبيه Konica ما زالت مطلوبة. قائمة Windows لا تثبت اتصال Wi‑Fi.

الطابعات الافتراضية التي لا تدخل في الترقيم: Adobe PDF، Microsoft Print to PDF، OneNote (Desktop)، PDFill PDF&Image Writer.

## ما يلزم قبل التشغيل اليومي

1. اتباع [دليل الإعداد العربي](SETUP_AR.md) لإنشاء Supabase وRender؛ لا تعِد استخدام قاعدة أو مفتاح مكتبة الهندسة.
2. التأكد من أن `/api/ready` يعرض `database`, `storage`, و`jwt` على أنها `true`.
3. إنشاء المدير الأول، ثم إزالة `ADMIN_SETUP_PIN` من Render.
4. تسمية الطابعات كما في القائمة وإصلاح تنبيه Epson وKonica، ثم تحديد الورق الفعلي وتجربة الطباعة.
5. تجربة مشاركة الملفات على Android بعد تثبيت الموقع، ومراجعة طلب طالب/موظف/مدير للتأكد من ظهور ما يلزم لكل دور.
6. تحديد مدة الاحتفاظ بملفات الطلبات والنسخ الاحتياطي قبل إدخال بيانات طلاب حقيقية.

الخطة المجانية مناسبة للمعاينة الأولية فقط؛ الاعتماد اليومي في المكتبة يحتاج خطة استضافة مدفوعة مناسبة. أما أسماء قائمة الطباعة داخل التطبيق فهي تسميات مساعدة؛ متصفح الموظف هو الذي يختار طابعة Windows أو الهاتف.
